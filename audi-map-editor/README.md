# Audi EDC17 map editor

Десктопный редактор калибровочных карт для прошивок Bosch EDC17 (Audi / VAG).
Открывает «сырой» дамп флеш-памяти (`.bin` / `.ori`, 4 МБ), показывает карты как
2D-таблицу с heatmap и 3D-поверхность, ищет оси/карты по сигнатурам и пишет
правки обратно в файл.

Тестовый стенд: **EDC17CP44 / TC1797**, прошивка `4G0907401B` — Audi A6 C7
3.0 TDI CDUC.

## Что умеет

- Идентификация ECU по строкам в прошивке (вариант, TC1xxx, SW-номер, EPK,
  партномер VAG, описание двигателя).
- Hex-вьюер с подсветкой адресов выделенной карты.
- Просмотр карт: heatmap-таблица + 3D-поверхность (matplotlib).
- Редактирование значений ячеек напрямую — правка сразу пишется в буфер
  прошивки (физическое значение пересчитывается обратно через factor/offset).
- Сохранение изменений в новый `.bin` (исходный файл не трогается, если
  использовать «Save bin as…»).
- Эвристический сканер: ищет в указанном диапазоне монотонно возрастающие
  последовательности int16/uint16 (оси), затем пары осей с правдоподобным
  блоком данных после Y-оси → кандидаты на 3D-карты.
- Описания карт сохраняются как JSON-проект (`*.ame.json`), чтобы не вводить
  адреса заново для одной и той же ревизии прошивки.

## Чего пока нет

- Пересчёта контрольных сумм EDC17 (`CRC checksum recalc`). Залить
  изменённый файл обратно в ECU без правки checksum, скорее всего, не
  получится: EDC17 проверяет PFlash при старте. Понадобится — добавим как
  отдельный модуль под конкретный подвариант (CP44/CP54/C46/CP14).
- Импорта DAMOS / A2L / XDF — на этом этапе работаем по адресам, найденным
  сканером или вручную.
- Расшифровки прошитых блоков (encrypted SW). Карты обычно лежат в
  нешифрованном «DS1»-блоке (для CP44: `0x340000–0x3FFFFF`), его и
  редактируем.

## Запуск (из исходников)

Требуется Python 3.10+.

```bash
cd audi-map-editor
python3 -m venv .venv
source .venv/bin/activate           # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python run.py
```

## Сборка .exe для Windows

Сборка нативного `.exe` возможна только на Windows (PyInstaller не умеет
кросс-компилировать). Есть два пути:

**Вариант A — собрать на своём ПК (Windows + Python 3.10+):**

```cmd
cd audi-map-editor
build_exe.bat
```

Скрипт создаст `.venv`, поставит зависимости, прогонит PyInstaller и
положит результат в `dist\audi-map-editor\audi-map-editor.exe`. Папку
`dist\audi-map-editor\` можно скопировать целиком на любой Windows-ПК
без Python.

**Вариант B — собрать в GitHub Actions:**

Запушьте ветку `claude/audi-map-editor-Zoy7m` (или нажмите «Run workflow»
в GitHub → Actions → «Build Audi EDC17 map editor»). На windows-раннере
соберётся `audi-map-editor-windows.zip`, скачать можно с вкладки
Actions → Artifacts.

В меню `File → Open .bin…` открываем прошивку. `Tools → Scan…` находит
кандидатов на карты в блоке данных EDC17 (по умолчанию `0x340000–0x3FFFFF`).
Из результатов сканирования двойным кликом добавляем карту в проект, потом
открываем её в редакторе.

## Структура

```
audi-map-editor/
├── ame/
│   ├── app.py            # точка входа QApplication
│   ├── main_window.py    # главное окно, меню, доки
│   ├── binfile.py        # I/O бинарника + типизированный доступ
│   ├── mapdef.py         # MapDef / AxisDef / Project (JSON)
│   ├── edc17.py          # идентификация прошивки EDC17
│   ├── scanner.py        # эвристика осей и пар axis+axis+data
│   ├── hex_view.py       # hex-вьюер на QAbstractScrollArea
│   ├── map_widgets.py    # таблица с heatmap + 3D-поверхность
│   └── dialogs.py        # диалоги «определение карты» и «сканер»
├── run.py
├── requirements.txt
└── samples/
    └── AXXX19ED.ori      # ваш сток (для разработки/тестов)
```

## Безопасность

Файл прошивки открывается полностью в память, в исходный путь ничего не
пишется до явного `Save .bin` / `Save .bin as…`. Желательно держать рядом
немодифицированный «сток» (`samples/AXXX19ED.ori`) — его можно открыть в
read-only режиме параллельно, если поднять второе окно. При первом успешном
запуске рекомендуется сразу сохранить копию через `Save .bin as…` под
другим именем, чтобы случайно не затереть оригинал.
